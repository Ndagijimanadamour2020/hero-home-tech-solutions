# Hero Home Tech Solutions - Official Website

Enterprise digital assessment and service platform for Hero Home Tech Solutions.

## Features
- **Tech Stack**: Next.js 14 (App Router), TypeScript, Tailwind CSS, Lucide Icons.
- **Conversion Focused**: Built-in "Free Digital Assessment" lead capture form with server API route (`/api/assessment`).
- **Interactive Portfolio**: Filterable project gallery with real business outcome callouts.
- **WhatsApp Direct Integration**: Floating WhatsApp chat button configured for fast client communication.
- **SEO & Performance Optimized**: Mobile-first, high contrast slate dark design mode.

## How to Run Locally

1. **Extract Zip & Open Directory**:
   ```bash
   cd hero-home-tech-solutions
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deploying to Vercel (Recommended)

1. Push this repository to GitHub.
2. Sign in to [Vercel](https://vercel.com).
3. Click **"Add New Project"** and select your GitHub repository.
4. Click **Deploy**. Vercel will automatically build and deploy your Next.js application with zero manual setup!
